# Wispra releases

Installers and release notes for **Wispra**: voice dictation and meeting notes for Windows and macOS.
Website: [wispra-web.vercel.app](https://wispra-web.vercel.app)

This repository holds only the published installers and their release notes. It has no source code.

## Download

Get the latest version from the [latest release](https://github.com/sinhgiang/wispra-releases/releases/latest):

- **Windows:** `Wispra-Setup-<version>.exe`
- **macOS:** `Wispra-<version>-universal.dmg`

Wispra updates itself: when a new version is out, the app offers it and installs it on restart.

## What's new

Every version's notes are on the [Releases page](https://github.com/sinhgiang/wispra-releases/releases) and on
[wispra-web.vercel.app/updates](https://wispra-web.vercel.app/updates).
